# My Shortner

A lightweight PHP URL shortener for creating short, trackable links with custom aliases and QR codes.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Features

- Shorten long URLs
- Custom short codes
- QR code generation
- Click tracking
- Input validation
- Duplicate URL detection
- Responsive UI
- Apache rewrite support

## Requirements

- PHP 7.4+
- MySQL or MariaDB
- Composer
- Apache with mod_rewrite

## Installation

Clone the repository and install dependencies:

    git clone https://github.com/rafidahmed870/my-shortner.git
    cd my-shortner
    composer install

Configure your environment using `.env.example`.

Import the database schema from:

    config/schema.sql

## Local Setup

For XAMPP or WampServer:

1. Place the project inside the `htdocs` directory.
2. Start Apache and MySQL.
3. Open the project in your browser.
